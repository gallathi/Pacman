Pour jouer à Pacman, veuillez effectuer les étapes suivantes :
  - Ouvrir main.py avec Spyder
  - Installer le module pygame (pip install pygame) dans votre terminal Spyder
  - Lancer le programme
  - Si une erreur liée aux images s'affiche, c'est un bug de Spyder, il suffit de le redémarrer
  - Choisir le niveau de difficulté (détaillé dans la console)
  - Plus qu'à appuyer sur le bouton start de la fenêtre graphique !


Règles de Pacman :  

    L’objectif du jeu est de terminer les différents niveaux en accumulant le plus de score possible. Pour ce faire, le joueur doit déplacer le personnage Pacman avec les flèches directionnelles pour ramasser tous les points de la carte, tout en évitant les fantômes. En cas de contact avec un fantôme, Pacman perdra une vie et reviendra à sa position de départ.
Le joueur peut également récolter des bonus : des fruits apparaissant périodiquement apportent un boost de score et les 4 pacgommes par carte inversent les rôles (Pacman peut manger les fantômes ce qui lui apportera du score) pendant un temps donné.
Le jeu se termine lorsque Pacman n'a plus de vies, essayez de faire le plus grand score possible !
